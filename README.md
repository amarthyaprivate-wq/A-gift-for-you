# A Gift For You

A personalized, animated tulip-garden greeting page with a heartfelt letter overlay.

Fork of an original work "Tulip Flower" (https://codepen.io/cherkalexander/pen/EagyGZw),
itself a fork of "Tulip Flower" by Faiza Farooq (https://codepen.io/Faiza_Farooq_SR/pen/MYYWPze).

## Structure

```
A-gift-for-you/
├── dist/          # production-ready build, deploy this folder
│   ├── index.html
│   ├── style.css
│   └── script.js
├── src/           # source files
│   ├── index.html
│   ├── style.css
│   └── script.js
├── README.md
├── LICENSE.txt
└── netlify.toml
```

## Running locally

Just open `dist/index.html` (or `src/index.html`) in a browser — no build step required.

## Deploying to Netlify

This repo includes a `netlify.toml` that points Netlify at the `dist` folder. Drag the
project folder into Netlify, or connect the repo, and it will publish automatically.
